# Sistema Acadêmico

Projeto acadêmico desenvolvido para a disciplina de **Projeto e Engenharia de Software**, com o objetivo de aplicar conceitos de programação, modelagem, organização de código, persistência de dados e testes de software.

O sistema permite realizar operações básicas de gerenciamento acadêmico por meio de um menu interativo no terminal, utilizando Python e SQLite.

## Objetivo do projeto

Desenvolver um sistema acadêmico simples, organizado em camadas e com persistência de dados, aplicando na prática os conhecimentos estudados durante a graduação.

## Funcionalidades

- Cadastro e listagem de alunos.
- Cadastro e listagem de disciplinas.
- Matrícula de alunos em disciplinas.
- Prevenção de matrículas duplicadas.
- Registro de duas avaliações por matrícula.
- Cálculo automático da média das avaliações.
- Definição da situação acadêmica do aluno.
- Armazenamento dos dados em banco de dados SQLite.
- Testes automatizados das regras de matrícula.

## Tecnologias utilizadas

- **Python 3.10+** — linguagem de programação.
- **SQLite** — banco de dados relacional.
- **unittest** — testes automatizados.
- **Git e GitHub** — versionamento e hospedagem do código-fonte.

O projeto utiliza recursos da biblioteca padrão do Python, sem necessidade de instalar dependências externas.
